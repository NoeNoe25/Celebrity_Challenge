# Rihanna Tribute Page (SheCodes Challenge)

A single-page tribute website about Rihanna, built for a SheCodes front-end challenge. It is organised in three themed sections: **The Artist**, **The CEO** (Fenty Beauty and Fenty) and **The Activism**, with a discography gallery and headline stats.

## Built with

HTML5 · CSS3 (one stylesheet per section) · Bootstrap 5 · Google Fonts (Nunito Sans, Source Serif 4) · Material Symbols

## Files

| File | Purpose |
| --- | --- |
| `home.html` | The page |
| `home.css`, `menu.css`, `footer.css` | Layout, navigation, footer |
| `artist.css`, `ceo.css`, `ngo.css` | Section styles |
| `nav.html` | Navigation prototype |

## View it

Open `home.html` in a browser. Images load from the SheCodes CDN, so an internet connection is needed.
